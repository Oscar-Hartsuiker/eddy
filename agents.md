# eddy

A simple modern minimalist lightweight photo editor application

## Features (right Sidebar)

### Sliders (visable in default mode)

Exsposure
Brightness
Contrast
Saturation

### Curves (visable in default)

### Buttons

Crop
Rotate
flip
zoom in, out
zoom fit

### Saving

Ctrl + S = Save (overwrite)

Ctr + Shift + S Save as

### Notes

Should save in original format by default
Must support png webp and jpeg
To be used from manager or terminal only one image per window
